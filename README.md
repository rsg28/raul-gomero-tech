# Creative Portfolio Website

A stunning, modern portfolio website built with React, featuring beautiful animations, interactive elements, and a creative design.

## 🚀 Features

### Visual Design
- **Animated Hero Section** with particle effects and typing animations
- **Interactive Navigation** with smooth scrolling and responsive design
- **Creative Layouts** with gradient backgrounds and floating elements
- **Modern Typography** using Google Fonts (Poppins & Playfair Display)

### Components
- **Hero Section**: Particle animation system, typing effects, floating geometric shapes
- **About Section**: Interactive cards, animated statistics, personal story
- **Skills Section**: Animated progress bars, tech icons, experience timeline
- **Projects Section**: Filterable portfolio, modal previews, hover effects
- **Contact Section**: Form validation, animated inputs, social links
- **Footer**: Social media links, scroll-to-top functionality

### Technical Features
- **Framer Motion Animations**: Smooth, performant animations throughout
- **Responsive Design**: Optimized for all device sizes
- **Intersection Observer**: Scroll-triggered animations
- **Form Validation**: Real-time validation with error handling
- **Performance Optimized**: Lazy loading and efficient rendering

## 🛠️ Technologies Used

- **React 18** - Modern React with hooks
- **Vite** - Fast build tool and development server
- **Framer Motion** - Animation library
- **Typed.js** - Typing animation effects
- **React Icons** - Icon library
- **CSS3** - Modern styling with custom properties
- **JavaScript ES6+** - Modern JavaScript features

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/creative-portfolio.git
   cd creative-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🎨 Customization

### Personal Information
Edit the following files to customize with your information:
- `src/components/Hero/Hero.jsx` - Name and titles under the hero section
- `src/components/About/About.jsx` - Personal description and statistics
- `src/components/Skills/Skills.jsx` - Skills and experience timeline
- `src/components/Projects/Projects.jsx` - Portfolio projects
- `src/components/Contact/Contact.jsx` - Contact information and social links

### Styling
- `src/index.css` - Global styles and CSS variables
- Component-specific CSS files for individual styling

### Colors and Themes
Modify CSS custom properties in `src/index.css`:
```css
:root {
  --primary-color: #6366f1;
  --secondary-color: #8b5cf6;
  --accent-color: #f59e0b;
  /* ... more variables */
}
```
